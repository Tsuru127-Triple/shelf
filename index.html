試験機能

チャンネルを選ぶと、その月の何日に動画を投稿したかをサムネつきのカレンダーで確認できます。

YouTube Data APIキー

キーはこのブラウザの中だけに保存され、Googleへの問い合わせ以外には使われません。

取得方法：Google Cloud Console でプロジェクトを作成 → 「YouTube Data API v3」を有効化 → 「認証情報」から「APIキー」を作成。キーの制限は「APIの制限」でYouTube Data API v3のみに絞るのがおすすめです。

登録チャンネルの自動同期

連携すると「更新」のたびにYouTubeの登録チャンネルと同じ状態に揃えます。新しく登録したチャンネルは未分類に追加され、登録解除したチャンネルはこのアプリからも消えます。YouTubeの設定で登録チャンネルを公開にしておく必要があります。

バックアップ

ブラウザのデータを消すとリスト分けも消えるので、ときどき書き出しておくと安心です。APIキーは含まれません。

よくある質問

APIキーって何？どこで作る？

YouTubeから動画情報を取得するための鍵です。上の「初期設定ガイド」で画像付きで手順を確認できます。Google Cloud Consoleでプロジェクトを作り、「YouTube Data API v3」を有効にして「認証情報」→「APIキー」で作成します。「OAuth同意画面を構成してください」という警告は、APIキーだけ使うなら無視して大丈夫です。

APIの使用量はどれくらい？

1日1万までの無料枠があり、日本時間16〜17時ごろにリセットされます。「更新」は1回でおよそ登録チャンネル数＋数十、チャンネル検索とおすすめの取得は1回100使います。

新しい版のファイルに差し替えるには？

新しいファイルをダウンロードしてChromeで開くだけです。APIキーやリストはブラウザに保存されているので引き継がれます。念のため、差し替え前にバックアップを書き出しておくと安心です。

「今週の動画」と「一覧」の違いは？

「今週の動画」は今週月曜0時以降、「一週間の動画」は今日を含む直近7日間、「一覧」はそれより前の動画です。見出しのプルダウンで切り替えられます。一覧は50本ずつ表示し、最後まで見ると「さらに前の動画を読み込む」で過去の動画を追加取得できます（ブラウザを更新すると元に戻ります）。

表示を切り替えるには？

各見出しの右にあるアイコンで、リスト・タイル・グリッドをタブごとに選べます。目の斜線アイコンで見た動画を隠し、チェック2つのアイコンでまとめて視聴済みにできます。

視聴済みはどう判定している？

このアプリ上でクリックした動画だけを視聴済みにしています。YouTubeで直接見た動画は、APIの仕様上反映できません。

アプリ内で動画を再生できない？

手元のファイルとして開いている場合、YouTubeの埋め込み再生は仕様上エラーになるため、クリックするとYouTubeが開く形にしています。

登録チャンネルを自動で反映するには？

YouTubeの設定で登録チャンネルを公開にし、この画面の「登録チャンネルの自動同期」で自分のチャンネルを連携してください。更新のたびに登録・解除が反映されます。アプリ内で手動追加したチャンネルは消えません。

リストの作り方・並べ替え・チャンネルの追加は？

左の「＋ リストを作成」で作り、リスト横の「⋯」からチャンネル追加・名前変更・削除ができます。左下の「並べ替え」でドラッグして順番を変えられます。

ショートが混ざることがある

チャンネルのショート一覧と照合して除外していますが、YouTube公式の仕組みではないため、まれに漏れることがあります。

おすすめはどうやって選んでいる？

リスト名（または「⋯」→「おすすめのキーワード」で設定した語句）でYouTubeを検索し、登録済みチャンネルとショートを除いて表示しています。「興味なし」を押すと次の候補に入れ替わります。結果は1日保存されます。

リスト横の青い点は？

今日公開・配信された動画があるリストに付きます。「⋯」→「本日の動画をおすすめしない」で、そのリストだけ非表示にできます。

「YouTubeで探して追加」したチャンネルは？

このアプリ内だけの登録です。YouTubeのチャンネル登録はされません。

データ

APIキー・リスト・視聴済みの記録など、このブラウザに保存されたSHELFのデータをすべて消します。

SHELFはYouTube APIサービスを利用しています。利用にあたってはYouTube利用規約に同意したものとみなされます。
